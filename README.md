# pad-amp-nhd-val

External validation of three published integer risk scores against **non-home discharge
(NHD)** after major lower extremity amputation. Strategus-based, following the
`pad-amp-ed-desc` pattern.

This is a **frozen, validation-only fork of `pad-amp-nhd-prog`** (forked 2026-09-07),
made to keep this analysis stable for a publication while `pad-amp-nhd-prog` itself
continues toward a de-novo risk score. It carries the same disabled
`ENABLE_PLP_DEVELOPMENT` scaffold `pad-amp-nhd-prog` has (see below) simply because it
was forked before that flag was ever flipped — de-novo model development happens in
`pad-amp-nhd-prog`, not here.

| Score | Range | Published lookup |
|---|---|---|
| Iannuzzi 2020 NHD score | 0–18 | yes (isotonic fit over the published table) |
| Subramaniam 2018 mFI-5 | 0–5 | no |
| Kraiss 2022 sVQI-FS | 0–10 (10 of 11 items) | no |

## Quick start

```bash
Rscript -e 'renv::restore(prompt = FALSE)'
Rscript CreateStrategusAnalysisSpecification.R   # step 1: build the spec
Rscript StrategusCodeToRun.R                     # step 2: execute + score + report
```

Run everything through the dev container:

```bash
docker exec omop_dev-devcontainer-1 bash -lc 'cd /workspace/pad-amp-nhd-val && Rscript StrategusCodeToRun.R'
```

## What runs where

Strategus generates the cohorts and the Table 1 characterization. It does **not** score
the three instruments — applying a fixed set of published weights is not what
`PatientLevelPredictionModule` does (it fits models). Scoring runs as a custom step after
`Strategus::execute()`, in `scripts/analysis/integer_score_validation.R`, reading the
cohort table Strategus just populated.

## Data source

Physical CDM `omop_synth_pad_amp_dispo`, generated by
[`pad-amp-dispo-synth`](https://github.com/Duke-Vascular-Informatics/pad-amp-dispo-synth) and registered
in `synthetic_data/registry.yaml` as `pad_amp_dispo`. Synthetic only — no real patients.

Strategus reads a view-overlay unioning that CDM with `omop_vocab`; the runner builds it
automatically if absent.

## Cohorts

See `inst/Cohorts.csv` for the full rationale of every cohort.

- **Reused from `pad-amp-ed-desc`:** the legacy target (`1797941`).
- **Authored here, shared with `pad-amp-nhd-prog` (`9100001–9100011`):** the NHD outcome
  and target plus score-faithful COPD, PAOD, ischemic tissue loss, insulin-treated
  diabetes, two anemia thresholds, and renal impairment.
- **Authored here, this repo only (`9100021–9100027`, 2026-10-05):** diabetes, hypertension,
  heart failure, coronary artery disease, pneumonia, ADL-dependent functional status and
  ambulatory status. Generated by `scripts/author_covariate_cohorts.R`.

Every covariate cohort is `Limit: All`, so the score items' lookback windows bind (365 days
by default; mFI-5 heart failure and pneumonia use 30). The four reused VA-FI comorbidity
cohorts were dropped because `Limit: First` meant a window could never bind. COPD and PAOD
are authored rather than reused because the VA-FI cohorts of those names are faithful VA
Frailty Index *deficits* — broad organ-system categories that include asthma and interstitial
lung disease, or aortic aneurysm and venous thrombosis. Correct for VA-FI; not what the
published score items mean.

## Regression test

```bash
Rscript tests/regression/test_cohort_vs_domain_covariates.R
```

Scores each instrument twice — once resolving covariates from the Strategus cohort table,
once by querying the CDM directly — and compares person-level counts. Covariates whose
semantics are identical across both paths must match **exactly** — since 2026-10-05 that is
every covariate, including mFI-5's COPD-or-pneumonia item. Per-covariate deltas are written to
`output/regression/cohort_vs_domain_deltas.csv`.

## Known limitations

- On the current synthetic dataset the module generates NHD **unconditionally** of
  frailty, so discrimination sits near chance (AUROC ≈ 0.47–0.54) by construction. The
  pipeline is being exercised, not the clinical hypothesis.
- `age_ge80` activates in 0% — the generator's age guard plus exposure delay cap index age
  near 81, and it carries Iannuzzi's largest single weight (6 points). Fixable upstream by
  widening the exposure-onset delay.
- The de-novo model arm is scaffolded but **disabled** (`ENABLE_PLP_DEVELOPMENT <- FALSE`);
  predictors and approach are a study-team decision.

See `CLAUDE.md` for the full set of gotchas.
