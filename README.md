# pad-amp-nhd-prog

External validation of three published integer risk scores against **non-home discharge
(NHD)** after major lower extremity amputation, with a scaffold for de-novo model
development. Strategus-based, following the `pad-amp-ed-desc` pattern.

| Score | Range | Published lookup |
|---|---|---|
| Iannuzzi 2020 NHD score | 0–18 | yes (isotonic fit over the published table) |
| Subramaniam 2018 mFI-5 | 0–5 | no |
| Kraiss 2022 sVQI-FS | 0–10 (10 of 11 items) | no |

## Quick start

```bash
Rscript -e 'renv::restore(prompt = FALSE)'
Rscript CreateStrategusAnalysisSpecification.R   # step 1: build the spec
Rscript StrategusCodeToRun.R                     # step 2: execute + score + report
```

Run everything through the dev container:

```bash
docker exec omop_dev-devcontainer-1 bash -lc 'cd /workspace/pad-amp-nhd-prog && Rscript StrategusCodeToRun.R'
```

## What runs where

Strategus generates the cohorts and the Table 1 characterization. It does **not** score
the three instruments — applying a fixed set of published weights is not what
`PatientLevelPredictionModule` does (it fits models). Scoring runs as a custom step after
`Strategus::execute()`, in `scripts/analysis/integer_score_validation.R`, reading the
cohort table Strategus just populated.

## Data source

Physical CDM `omop_synth_pad_amp_dispo`, generated by
[`pad-amp-dispo-synth`](https://github.com/Duke-Vascular-Informatics/pad-amp-dispo-synth) and registered
in `synthetic_data/registry.yaml` as `pad_amp_dispo`. Synthetic only — no real patients.

Strategus reads a view-overlay unioning that CDM with `omop_vocab`; the runner builds it
automatically if absent.

## Cohorts

15 total, listed with full rationale in `inst/Cohorts.csv`.

- **Reused from `pad-amp-ed-desc`:** the target (`1797941`) and four VA-FI comorbidity
  cohorts (`cad`, `chf`, `htn`, `dm`).
- **Authored here (`9100001–9100010`):** the NHD outcome plus score-faithful COPD and
  PAOD, ischemic tissue loss, dependent functional status, ambulatory deficit,
  insulin-treated diabetes, two anemia thresholds, and renal impairment.

COPD and PAOD are authored rather than reused because the VA-FI cohorts of those names are
faithful VA Frailty Index *deficits* — broad organ-system categories that include asthma
and interstitial lung disease, or aortic aneurysm and venous thrombosis. Correct for
VA-FI; not what the published score items mean.

## Regression test

```bash
Rscript tests/regression/test_cohort_vs_domain_covariates.R
```

Scores each instrument twice — once resolving covariates from the Strategus cohort table,
once by querying the CDM directly — and compares person-level counts. Covariates whose
semantics are identical across both paths must match **exactly**; the four reused
`Limit: First` VA-FI cohorts are expected to differ, and the size of that difference is
written to `output/regression/cohort_vs_domain_deltas.csv`.

## Known limitations

- On the current synthetic dataset the module generates NHD **unconditionally** of
  frailty, so discrimination sits near chance (AUROC ≈ 0.47–0.54) by construction. The
  pipeline is being exercised, not the clinical hypothesis.
- `age_ge80` activates in 0% — the generator's age guard plus exposure delay cap index age
  near 81, and it carries Iannuzzi's largest single weight (6 points). Fixable upstream by
  widening the exposure-onset delay.
- The de-novo model arm is scaffolded but **disabled** (`ENABLE_PLP_DEVELOPMENT <- FALSE`);
  predictors and approach are a study-team decision.

See `CLAUDE.md` for the full set of gotchas.
